# DocCraft AI Help Center

A 7-page knowledge base and support hub for DocCraft AI — covering getting started, all core features, workflow guides, UI reference, troubleshooting, FAQ, and release notes.

## Live Demo

Hosted on GitHub Pages: `sulagnasasmal.github.io/doccraft-help-center/`

## Pages

| Page | Content |
|------|---------|
| `index.html` | Help center home — search, featured articles, quick links |
| `getting-started.html` | Account setup, first document, key concepts |
| `feature-generate.html` | AI generation — inputs, templates, prompts, context layer |
| `workflows.html` | End-to-end documentation workflows and best practices |
| `ui-reference.html` | Complete UI reference — all panels, buttons, and settings |
| `faq.html` | Frequently asked questions |
| `troubleshooting.html` | Common errors, fixes, and support escalation paths |
| `release-notes.html` | Version history and new feature announcements |

## Tech Stack

- HTML (89.8%), CSS (9.7%), JavaScript (0.5%)
- No frameworks, no build pipeline
- Client-side search
- Outfit / Inter / JetBrains Mono (Google Fonts)

## Dark / Light Mode

All pages support dark and light themes via a toggle button (◐ / ☀) in the navigation bar. Theme preference persists in `localStorage`. System `prefers-color-scheme` is respected on first visit.
