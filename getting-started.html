Quickstart: Generate Your First Document

Last updated: February 2025 · 5 minute read

Before You Begin

You need a DocCraft account to follow this guide. Sign up free at doccraft-ten.vercel.app — no credit card required.

This guide walks you from a fresh DocCraft account to your first generated document in under 3 minutes. By the end, you'll have a professionally formatted API reference, README, or user guide ready to review and export.

1
Create Your Account

Navigate to doccraft-ten.vercel.app and click Get Started Free. You can sign up with Google or an email address.

After signing up, you'll land on your DocCraft Dashboard — the central control panel where all your generated documents live. The dashboard shows your recent projects, credit usage, and quick-access generation buttons.

Free Tier

Free accounts include 10 document generations per month. Each generation uses your source material to produce one complete document. There are no time limits or expiring credits.

2
Upload Your Source Material

DocCraft accepts three input types — choose whichever matches your project:

  • GitHub repository URL — paste a public repo URL. DocCraft reads README files, code comments, and directory structure to understand your project.
  • OpenAPI / Swagger specification — upload a .yaml or .json spec file. DocCraft generates a complete API reference with endpoint descriptions, parameters, and example requests.
  • Plain text description — paste a product description, feature brief, or any prose. DocCraft uses this as context to generate documentation in your desired format.
Tip — Better Input, Better Output

The quality of your generated documentation correlates directly with the richness of your input. A well-commented codebase or a detailed OpenAPI spec with descriptions produces far more accurate output than a barebones spec with no descriptions.

3
Choose a Document Type

After uploading your source, select the type of documentation you want DocCraft to generate:

  • API Reference — Full endpoint-by-endpoint reference. Best with OpenAPI or Postman input. Generates: overview, authentication guide, endpoint table, request/response schemas.
  • README — GitHub-style project README. Good for code repos. Generates: intro, installation steps, usage examples, configuration reference, contributing guide.
  • User Guide — Step-by-step product documentation for end users. Good for SaaS products. Generates: getting started, feature walkthroughs, FAQs.
  • Admin Guide — System administration and configuration documentation. Generates: installation, system requirements, config options, security settings, maintenance procedures.
  • Release Notes — Version-by-version changelog. Good for products with commit history or feature lists. Generates: formatted release entries with New Features, Improvements, Bug Fixes sections.
4
Generate and Review

Click Generate. DocCraft's AI processes your source material — typically in 15–45 seconds depending on the size and complexity of your input. A progress indicator shows generation status.

Once generation completes, the document opens in DocCraft's built-in Document Editor. This is a full-featured markdown editor where you can:

  • Edit any section inline using the rich text or raw markdown editor
  • Add, remove, or reorder sections using the sidebar outline panel
  • Ask DocCraft to regenerate a specific section with different instructions ("make this section more concise" / "add code examples for Python")
  • Apply a template to reformat the document structure
Generation takes 15–45 seconds

Do not navigate away from the page during generation. If your browser tab goes inactive for a long period, the generation may need to be retried. Generation results are saved automatically once complete.

5
Export Your Document

When you're satisfied with the output, export it in any of the supported formats:

  • Markdown (.md) — plain markdown for use in GitHub, Git repos, or static site generators
  • HTML (.html) — standalone HTML page with embedded styles, ready to publish
  • PDF — print-quality PDF generated from your document layout
  • Confluence — publish directly to a Confluence space via API integration (requires workspace URL and token)

All export options are available from the Export button in the top-right corner of the editor toolbar. Exported files are also available in your Dashboard for 30 days.

🎉 You've generated your first document!

Explore more doc types, try the templates library, or connect your Confluence workspace to start publishing directly from DocCraft.
