Quickstart: Generate Your First Document

Last updated: March 2026 · 5 minute read

No Account Required

DocCraft's core features — analyze, generate, and export — work without signing in. Create a free account to unlock cloud save, team workspaces, and GitHub publishing.

This guide walks you through a complete generation cycle: upload source material, review AI-identified gaps, generate a document with live streaming, then edit and export. You'll have a professionally formatted document in under 3 minutes.

1
Upload Your Source Material

Navigate to doccraft-ten.vercel.app. The Upload & Configure stage opens immediately.

DocCraft accepts multiple input types:

  • File upload — Drag and drop or browse for .txt, .md, .json, .yaml, or code files.
  • Paste text — Paste any raw content, API specs, product descriptions, or code directly.
  • Multiple files — Upload several files at once; DocCraft combines them as source context.
Tip — Better Input, Better Output

The richer your source material, the more accurate the generated document. Include code comments, API descriptions, or product context for best results.

2
Configure Document Settings

In the right sidebar, choose your document settings:

  • Document type — User Guide, Quick Start, API Reference, Troubleshooting Guide, or Release Notes. DocCraft may suggest the best type based on your content.
  • Audience — Non-technical, Technical, or Mixed.
  • Tone — Formal, Conversational, or Instructional.
  • Custom instructions — Any special requirements for the generation.

Optionally, add context documents (existing style guides, terminology glossaries) in the Context panel to improve accuracy.

3
Analyze & Review Gaps

Click Analyze & Identify Gaps. DocCraft's AI reviews your source material and presents 5–12 targeted questions about missing information, ambiguities, and assumptions.

For each gap question, you can:

  • Answer — Type your response to give the AI more context.
  • Skip — The AI will use its best judgment for that gap.

After reviewing gaps, click Generate Documentation.

4
Watch Live Streaming Generation

DocCraft generates your document using real-time streaming. You'll see tokens appear live in a "Live Draft" preview as the AI writes. A cancel button lets you stop early and keep whatever has been generated so far.

Once complete, the editor opens automatically with your full document.

5
Edit, Refine & Export

The Document Editor provides a split view (edit + preview) with powerful tools:

  • AI Refine — Select any text and apply actions: Simplify, Expand, Add Example, Troubleshoot, Make Concise.
  • MSTP Compliance Check — Run a compliance scan against Microsoft Style Guide rules.
  • Custom Compliance Rules — Apply your own governance rules on top of MSTP checks.
  • Version Diff — Compare your current draft with the original or any saved snapshot side-by-side.
  • Diagrams — Auto-generate Mermaid diagrams from your content.
  • Infographics — Create visual infographics from your document.
  • Export — Download as Markdown, HTML, or DOCX. Or publish to GitHub directly.
